## 🎯 Overview

**NextOwner.in** is a modern, full-stack resale marketplace built specifically for the Hyderabad and Telangana market. Whether you're selling a used car, a family home, or a commercial plot — NextOwner.in gives your listing professional visibility through social media reels, WhatsApp outreach, and a beautifully optimized web presence.

We bridge the gap between traditional word-of-mouth resale and modern digital reach — making every listing faster to sell, easier to find, and smarter to market.

## 🚀 Getting Started

### Prerequisites

Ensure the following are installed on your system:

- **Node.js** `v18+`
- **npm** `v9+`
- **MongoDB** (local) or a [MongoDB Atlas](https://www.mongodb.com/atlas) URI
- A [Cloudinary](https://cloudinary.com/) account

---

### 1. Clone the Repository

```bash
git clone https://github.com/kranthikumar-dev/nextowner.git
cd nextowner
```

### 2. Backend Setup

```bash
cd backend

# Install dependencies
npm install

# Create your environment file
cp .env.example .env
# → Fill in your values (see Environment Variables section)

# Start the development server
npm run dev
```

> The backend API will be running at `http://localhost:5000`

### 3. Frontend Setup

```bash
cd ../client

# Install dependencies
npm install

# Create your environment file
cp .env.example .env
# → Set VITE_API_URL to your backend URL

# Start the development server
npm run dev
```

> The frontend will be running at `http://localhost:5173`

## ⚙️ Environment Variables

### Backend — `backend/.env`

```env
# Server
PORT=5000

# Database
MONGO_URI=your_mongodb_connection_uri

# Authentication
JWT_SECRET=your_jwt_secret_key

# Cloudinary (Image Hosting)
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

### Frontend — `client/.env`

```env
# API Base URL
VITE_API_URL=http://localhost:5000/api
```

> ⚠️ **Never commit `.env` files to version control.** Add them to `.gitignore`.

## 🌐 Deployment

| Layer | Platform | Notes |
|---|---|---|
| **Frontend** | [Vercel](https://vercel.com/) | Auto-deploys from `main` branch |
| **Backend** | [Render](https://render.com/) | Node.js web service |
| **Database** | [MongoDB Atlas](https://www.mongodb.com/atlas) | M0 free tier or production cluster |
| **Images** | [Cloudinary](https://cloudinary.com/) | Auto CDN delivery |

### Deploying to Vercel (Frontend)

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
cd client
vercel --prod
```

### Deploying to Render (Backend)

1. Connect your GitHub repository on [Render Dashboard](https://dashboard.render.com/)
2. Set **Build Command**: `npm install`
3. Set **Start Command**: `npm start`
4. Add all environment variables from `backend/.env`
